# 詳細設計書：従業員管理アプリ（psys_flask）

## 1. システム構成

| 要素 | 内容 |
|------|------|
| フレームワーク | Flask |
| DB | MySQL（mysqlclient） |
| テンプレート | Jinja2（HTML） |
| 静的ファイル | CSS（style.css）、JS（未使用） |
| データ保存形式 | RDB（employeeテーブル） |
| 実行環境 | Windows11 + Python 3.10以上 |


## 2. データベース設計

### 2.1 テーブル：employee

| カラム名       | 型       | 主キー | NULL許可 | 備考             |
|----------------|----------|--------|----------|------------------|
| employee_no    | VARCHAR  | ○      | ×        | 社員番号（ID）   |
| employee_name  | VARCHAR  | ×      | ×        | 氏名             |
| password       | VARCHAR  | ×      | ×        | パスワード（平文）|


## 3. 画面設計

### 3.1 トップ画面（index.html）

| 項目 | 内容 |
|------|------|
| 表示内容 | 従業員一覧（社員番号・氏名・パスワード） |
| 操作 | 編集リンク（/edit/<id>）、削除リンク（/delete/<id>） |

### 3.2 新規登録画面（create.html）

| 項目 | 型 | 必須 | 備考 |
|------|----|------|------|
| 社員番号 | text | ○ | 主キー |
| 氏名 | text | ○ | 従業員名 |
| パスワード | text | ○ | 平文保存 |

### 3.3 登録確認画面（create_confirm.html）

- 入力内容を表示
- hiddenフィールドで値保持
- 「登録する」ボタン → `/confirm` POST

### 3.4 編集画面（edit.html）

- 既存データをフォームに表示
- hiddenで社員番号保持
- 「確認画面へ」 → `/edit/<id>` POST

### 3.5 編集確認画面（edit_confirm.html）

- 編集内容を表示
- hiddenで値保持
- 「更新する」 → `/edit_confirm` POST

### 3.6 削除確認画面（delete_confirm.html）

- 対象従業員の情報を表示
- hiddenで社員番号保持
- 「削除する」 → `/delete_confirm` POST


## 4. ルーティング設計（app.py）

| ルート | メソッド | 処理概要 |
|--------|----------|-----------|
| `/` | GET | 従業員一覧表示 |
| `/create` | GET/POST | 入力・確認表示 |
| `/confirm` | POST | DB登録処理 |
| `/edit/<id>` | GET/POST | 編集・確認表示 |
| `/edit_confirm` | POST | DB更新処理 |
| `/delete/<id>` | GET | 削除確認表示 |
| `/delete_confirm` | POST | DB削除処理 |


## 5. 処理設計

### 5.1 DB接続（get_db_connection）

```python
def get_db_connection():
    return MySQLdb.connect(**DB_CONFIG)
```

### 5.2 登録処理（/confirm）

```python
sql = "INSERT INTO employee (employee_no, employee_name, password) VALUES (%s, %s, %s)"
cursor.execute(sql, (no, name, password))
```

### 5.3 更新処理（/edit_confirm）

```python
sql = "UPDATE employee SET employee_name=%s, password=%s WHERE employee_no=%s"
cursor.execute(sql, (name, password, no))
```

### 5.4 削除処理（/delete_confirm）

```python
sql = "DELETE FROM employee WHERE employee_no=%s"
cursor.execute(sql, (no,))
```


## 6. 入力チェック仕様

| 項目 | チェック内容 |
|------|--------------|
| 社員番号 | 空欄禁止、重複不可（DB制約） |
| 氏名 | 空欄禁止 |
| パスワード | 空欄禁止 |


## 7. エラーハンドリング方針

| ケース | 対応方法 |
|--------|----------|
| DB接続失敗 | `try-except` で捕捉、エラーメッセージ表示 |
| SQL実行エラー | ログ出力、処理中断 |
| 存在しないID | 404相当の表示またはトップへ戻す |
| 入力不足 | HTMLの `required` 属性で制御 |
