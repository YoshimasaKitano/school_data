# 要件定義書：従業員管理アプリ（psys_flask）

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| 名称 | 従業員管理アプリ |
| 種別 | Webアプリケーション（Flask） |
| 対象 | 管理者が従業員情報を登録・編集・削除できる |
| 実行環境 | Windows11 / Python 3.10以上 / MySQL |
| 開発言語 | Python（Flask） |
| 使用ライブラリ | Flask, mysqlclient |

---

## 2. ディレクトリ構成

```
psys_flask/
├── app.py                 # Flaskアプリ本体
├── config.py              # DB接続設定（DB_CONFIG）
├── templates/             # HTMLテンプレート
│   ├── index.html         # 一覧画面
│   ├── create.html        # 新規登録画面
│   ├── create_confirm.html# 登録確認画面
│   ├── edit.html          # 編集画面
│   ├── edit_confirm.html  # 編集確認画面
│   ├── delete_confirm.html# 削除確認画面
├── static/
│   ├── css/style.css      # スタイルシート
│   └── js/                # JavaScript（未使用）
└── note.txt               # 補足メモ
```


## 3. 機能要件

### 3.1 従業員一覧表示

- `/` にアクセスすると全従業員情報を表示
- 表示項目：社員番号、氏名、パスワード

### 3.2 新規登録

| 項目 | 内容 |
|------|------|
| 入力画面 | `/create`（GET） |
| 確認画面 | `/create`（POST）→ `create_confirm.html` |
| 登録処理 | `/confirm`（POST）→ DB登録 → `/` にリダイレクト |

### 3.3 編集

| 項目 | 内容 |
|------|------|
| 編集画面 | `/edit/<id>`（GET） |
| 確認画面 | `/edit/<id>`（POST）→ `edit_confirm.html` |
| 更新処理 | `/edit_confirm`（POST）→ DB更新 → `/` にリダイレクト |

### 3.4 削除

| 項目 | 内容 |
|------|------|
| 確認画面 | `/delete/<id>`（GET）→ `delete_confirm.html` |
| 削除処理 | `/delete_confirm`（POST）→ DB削除 → `/` にリダイレクト |


## 4. 画面仕様（テンプレート）

| 画面 | 主な要素 |
|------|----------|
| index.html | 従業員一覧テーブル、編集・削除リンク |
| create.html | 入力フォーム（社員番号・氏名・パスワード） |
| create_confirm.html | 入力内容の確認、登録ボタン |
| edit.html | 編集フォーム（既存値表示） |
| edit_confirm.html | 編集内容の確認、更新ボタン |
| delete_confirm.html | 削除確認、削除ボタン |


## 5. データ仕様

### 5.1 テーブル構造：employee

| カラム名 | 型 | 説明 |
|----------|----|------|
| employee_no | VARCHAR | 社員番号（主キー） |
| employee_name | VARCHAR | 氏名 |
| password | VARCHAR | パスワード（平文）    |


## 6. 非機能要件

| 項目 | 内容 |
|------|------|
| DB接続 | `config.py` にて `DB_CONFIG` を定義 |
| 拡張性 | テンプレート分離、CSS、JS(未使用)   |
