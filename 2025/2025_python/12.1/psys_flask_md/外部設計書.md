# 外部設計書：従業員管理アプリ（psys_flask）

## 1. システム概要

| 項目 | 内容 |
|------|------|
| システム名 | 従業員管理アプリ |
| 開発方式 | Webアプリケーション（Flask） |
| 対象ユーザー | 管理者（社内利用） |
| 実行環境 | Windows11 / Python 3.10以上 / MySQL |
| 使用技術 | Flask, mysqlclient, HTML/CSS |

---

## 2. 画面一覧と機能概要

| 画面名 | URL | 主な機能 |
|--------|-----|----------|
| トップ画面 | `/` | 従業員一覧表示、編集・削除リンク |
| 新規登録画面 | `/create` | 従業員情報の入力 |
| 登録確認画面 | `/create`（POST） | 入力内容の確認 |
| 登録処理 | `/confirm` | DB登録、一覧へ遷移 |
| 編集画面 | `/edit/<id>` | 従業員情報の編集 |
| 編集確認画面 | `/edit/<id>`（POST） | 編集内容の確認 |
| 更新処理 | `/edit_confirm` | DB更新、一覧へ遷移 |
| 削除確認画面 | `/delete/<id>` | 削除前の確認表示 |
| 削除処理 | `/delete_confirm` | DB削除、一覧へ遷移 |

---

## 3. 画面遷移

```plaintext
[トップ画面] /
    ├─▶ [新規登録] /create
    │       └─▶ [登録確認] /create (POST)
    │               └─▶ [登録処理] /confirm → /
    ├─▶ [編集] /edit/<id>
    │       └─▶ [編集確認] /edit/<id> (POST)
    │               └─▶ [更新処理] /edit_confirm → /
    └─▶ [削除確認] /delete/<id>
            └─▶ [削除処理] /delete_confirm → /
```

---

## 4. 入出力項目定義

### 4.1 入力項目（create.html / edit.html）

| 項目名 | 型 | 必須 | 備考 |
|--------|----|------|------|
| 社員番号 | text | ○ | 主キー、重複不可 |
| 氏名 | text | ○ | 従業員名 |
| パスワード | text | ○ | 平文 |

### 4.2 出力項目（index.html）

| 項目名 | 内容 |
|--------|------|
| 社員番号 | 従業員の識別番号 |
| 氏名 | 従業員名 |
| パスワード | 登録されたパスワード（平文） |
| 操作 | 編集・削除リンク |

---

## 5. データ仕様

### 5.1 テーブル：employee

| カラム名 | 型 | 備考 |
|----------|----|------|
| employee_no | VARCHAR | 主キー |
| employee_name | VARCHAR | 氏名 |
| password | VARCHAR | パスワード（平文） |

---

## 6. インターフェース仕様

### 6.1 DB接続

- 設定ファイル：`config.py`
- 接続方式：MySQLdb
- 接続情報：`DB_CONFIG` にて定義（host, user, password, database）

### 6.2 HTTPメソッド

| URL | メソッド | 処理内容 |
|-----|----------|----------|
| `/` | GET | 一覧表示 |
| `/create` | GET/POST | 入力・確認 |
| `/confirm` | POST | 登録処理 |
| `/edit/<id>` | GET/POST | 編集・確認 |
| `/edit_confirm` | POST | 更新処理 |
| `/delete/<id>` | GET | 削除確認 |
| `/delete_confirm` | POST | 削除処理 |

---

## 7. エラーハンドリング（設計方針）

| ケース | 対応方針 |
|--------|----------|
| DB接続失敗 | エラーメッセージ表示、処理中断 |
| 入力値不足 | 必須項目チェック、再入力促す |
| SQL実行エラー | try-except で捕捉、ログ出力 |
| 存在しないID指定 | 404相当の表示またはトップへ戻す |

---
