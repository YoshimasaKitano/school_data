# 要求仕様書：図書館管理システム（Web版）

## 1. システム概要

| 項目 | 内容 |
|------|------|
| システム名 | 図書館管理システム（library_websystem） |
| 目的 | 蔵書と貸出履歴をWeb上で効率的に管理する |
| 技術構成 | Python（Flask）、MySQL、HTML/CSS　※Bootstrap使用可 |
| データ操作 | SQL文を直接記述（ORMは使用しない） |
| 対象ユーザー | 管理者、一般ユーザー |


## 2. 業務要求

| 要求ID | 要求内容 |
|--------|----------|
| RQ-01 | 管理者は蔵書の追加・検索・削除・更新ができること |
| RQ-02 | 一般ユーザーはユーザー登録後、貸出・返却・履歴確認ができること |
| RQ-03 | 本のタイトルは一意であること |
| RQ-04 | ユーザーは最大3冊まで借りられること |
| RQ-05 | Webブラウザから操作できること（PC、※スマホ対応） |
| RQ-06 | パスワード認証は未実装だが将来的に追加可能であること |


## 3. 機能要求

### 3.1 管理者機能

| 機能ID | 機能名 | 詳細 |
|--------|--------|------|
| FN-01 | 本の追加 | タイトルと著者名を入力し、重複チェック後に登録 |
| FN-02 | 本の検索 | キーワードによる部分一致検索。著者名と貸出状況を表示 |
| FN-03 | 本の削除 | タイトル指定で削除。存在しない場合はエラー表示 |
| FN-04 | 本の更新 | 著者名の変更。存在しない場合はエラー表示 |

### 3.2 ユーザー機能

| 機能ID | 機能名 | 詳細 |
|--------|--------|------|
| FN-05 | ユーザー登録 | ユーザー名を登録。既存ユーザーは履歴を引き継ぐ |
| FN-06 | 本の貸出 | 貸出可能な本を選択して借りる。最大3冊まで |
| FN-07 | 本の返却 | 借りている本を選択して返却 |
| FN-08 | 履歴確認 | 現在借りている本の一覧を表示 |


## 4. 非機能要求

| 要求ID | 区分 | 内容 |
|--------|------|------|
| NF-01 | 実行環境 | Python 3.x + Flask + MySQL |
| NF-02 | データ保存 | MySQL（books, users, borrowings） |
| NF-03 | UI | HTML/CSS（Jinja2テンプレート）、PC・スマホ対応 |
| NF-04 | セキュリティ | パスワード未実装（将来的に追加可能） |
| NF-05 | マイグレーション | schema.sql による手動管理。ORM未使用 |


## 5. データ要求
### 5.1 データベースの仕様
データベース名:lws_db

### 5.2 テーブル仕様

#### books

| カラム名 | 型 | 制約 |
|----------|----|------|
| id | INT | PRIMARY KEY, AUTO_INCREMENT |
| title | VARCHAR(255) | UNIQUE, NOT NULL |
| author | VARCHAR(255) | NOT NULL |
| available | BOOLEAN | NOT NULL |

#### users

| カラム名 | 型 | 制約 |
|----------|----|------|
| id | INT | PRIMARY KEY, AUTO_INCREMENT |
| username | VARCHAR(255) | UNIQUE, NOT NULL |

#### borrowings

| カラム名 | 型 | 制約 |
|----------|----|------|
| id | INT | PRIMARY KEY, AUTO_INCREMENT |
| user_id | INT | FOREIGN KEY (users.id) |
| book_id | INT | FOREIGN KEY (books.id) |
| borrowed_at | DATETIME | NOT NULL |


## 6. ルーティング仕様

| URL | メソッド | 処理内容 |
|-----|----------|----------|
| `/` | GET | ホーム画面表示 |
| `/admin/add` | GET/POST | 本の追加 |
| `/admin/search` | GET | 本の検索 |
| `/admin/delete` | POST | 本の削除 |
| `/admin/update` | POST | 本の更新 |
| `/user/login` | GET/POST | ユーザー登録・ログイン |
| `/user/borrow` | GET/POST | 本の貸出 |
| `/user/return` | GET/POST | 本の返却 |
| `/user/history` | GET | 履歴確認 |


## 7. エラーハンドリング仕様

| 条件 | メッセージ |
|------|------------|
| 重複登録 | 「すでに登録されています」 |
| 本が存在しない | 「見つかりません」 |
| 本が貸出中 | 「貸出できません」 |
| 本が借りられていない | 「その本は借りていません」 |
| 貸出冊数が上限 | 「最大3冊までです」 |
| SQLエラー | 「データベースエラーが発生しました」 |


## 8. 制約事項

- 本のタイトルは一意である必要がある。
- ユーザーは最大3冊まで借りることができる。
- Pythonのライブラリは、Flaskとmysqlclientのみとする。
- アプリケーションの操作はWebブラウザで行う。
- パスワード認証は実装しなくてよい。
- テーブル変更はSQLファイルを手動で実行する。
- READMEファイルを作成する。
