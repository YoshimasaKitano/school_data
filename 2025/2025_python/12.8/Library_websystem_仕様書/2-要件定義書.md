# 図書館管理システム 要件定義書（Web版）

## 1. システム名称  
図書館管理システム（library_websystem）
システム名:library_websystem

## 2. 背景・目的  
本システムは、図書館における蔵書の管理と利用者の貸出・返却履歴をWeb上で効率的に管理することを目的とする。PythonのFlaskフレームワークを用いて構築し、MySQLデータベースによりデータを永続化する。ORMは使用せず、SQL文を直接記述することで、データベース操作の理解を深め、軽量かつ柔軟な設計を実現する。



## 3. 対象ユーザー

| ユーザー種別 | 権限と役割 |
|--------------|------------|
| 管理者       | 蔵書の登録・検索・削除・更新を行う。 |
| 一般ユーザー | ユーザー登録後、本の貸出・返却・履歴確認を行う。 |



## 4. システム構成

| 項目             | 内容 |
|------------------|------|
| フレームワーク   | Flask |
| 言語             | Python 3.x |
| データベース     | MySQL |
| ORM使用          | なし（SQL文を直接記述） |
| マイグレーション | なし（schema.sqlにより手動管理） |
| UI               | HTML/CSS（Jinja2テンプレート） |
| 認証             | ユーザー名のみ（パスワードなし）※将来的に追加可能 |
| 同時利用         | セッション管理により複数ユーザー対応はなし |



## 5. 機能要件

### 5.1 管理者機能

| 機能名       | 詳細 |
|--------------|------|
| 本の追加     | タイトルと著者名を入力し、蔵書に登録。重複チェックあり。 |
| 本の検索     | キーワードによる部分一致検索。著者名と貸出状況を表示。 |
| 本の削除     | タイトルを指定して削除。存在しない場合はエラー表示。 |
| 本の更新     | 著者名の変更。存在しない場合はエラー表示。 |

### 5.2 ユーザー機能

| 機能名       | 詳細 |
|--------------|------|
| ユーザー登録 | 初回利用時にユーザー名を登録。既存ユーザーは履歴を引き継ぐ。 |
| 本の貸出     | 貸出可能な本を選択して借りる。1人最大3冊まで。 |
| 本の返却     | 借りている本を選択して返却。 |
| 履歴確認     | 現在借りている本の一覧を表示。 |



## 6. 非機能要件

| 項目         | 内容 |
|--------------|------|
| 実行環境     | Python 3.x + Flask + MySQL |
| データ保存   | MySQL（テーブル：books, users, borrowings） |
| UI           | Webブラウザ（PC・スマホ対応） |
| セキュリティ | パスワード未実装（将来的に追加可能） |
| 同時利用     | セッション管理により複数ユーザー対応 |


## 7. データ要件
### 7.1 データベース構成
データベース名:lws_db

### 7.1 テーブル構成

#### books テーブル
テーブル名:books

| カラム名     | 型         | 制約 |
|--------------|------------|------|
| id           | INT        | PRIMARY KEY, AUTO_INCREMENT |
| title        | VARCHAR(255) | UNIQUE, NOT NULL |
| author       | VARCHAR(255) | NOT NULL |
| available    | BOOLEAN     | NOT NULL |

#### users テーブル
テーブル名:users


| カラム名     | 型         | 制約 |
|--------------|------------|------|
| id           | INT        | PRIMARY KEY, AUTO_INCREMENT |
| username     | VARCHAR(255) | UNIQUE, NOT NULL |

#### borrowings テーブル
テーブル名:borrowings

| カラム名     | 型         | 制約 |
|--------------|------------|------|
| id           | INT        | PRIMARY KEY, AUTO_INCREMENT |
| user_id      | INT        | FOREIGN KEY (users.id) |
| book_id      | INT        | FOREIGN KEY (books.id) |
| borrowed_at  | DATETIME   | NOT NULL |



## 8. 制約事項

- 本のタイトルは一意である必要がある。
- ユーザーは最大3冊まで借りることができる。
- ORM（SQLAlchemyなど）は使用しない。
- GUIライブラリは使用せず、Webブラウザで操作。
- パスワード認証は未実装（将来的に追加可能）。
- テーブル変更はSQLファイルを手動で実行する。
