# 1. 特殊メソッドとは
Python の特殊メソッドは、**「ダンダー（dunder）メソッド」**とも呼ばれ、  
`__xxx__` のように前後をアンダースコア2つで囲んだ特別なメソッドのことです。  
クラスに特定の振る舞いを与えるために使われ、Python の文法と連動して自動的に呼び出されます。


- `__init__` や `__str__` のように **特別なタイミングで Python が自動的に呼ぶメソッド**  
- 演算子、比較、文字列化、コンテナ操作などをクラスに実装できる  
- オブジェクトを Python の文法に自然に溶け込ませるための仕組み

---

# 2. よく使う特殊メソッド一覧

## ■ 初期化・表示関連
| メソッド | 役割 |
|---------|------|
| `__init__(self)` | インスタンス生成時に呼ばれる（初期化） |
| `__str__(self)` | `print()` や `str()` で使う「人間向けの文字列」 |
| `__repr__(self)` | 開発者向けの文字列表現（デバッグ用） |

---

## ■ 演算子のオーバーロード
| メソッド | 対応する演算 |
|---------|--------------|
| `__add__(self, other)` | `+` |
| `__sub__(self, other)` | `-` |
| `__mul__(self, other)` | `*` |
| `__truediv__(self, other)` | `/` |

これらを定義すると、独自クラスでも数値のように演算できる。

---

## ■ 比較演算
| メソッド | 対応する比較 |
|---------|--------------|
| `__eq__(self, other)` | `==` |
| `__lt__(self, other)` | `<` |
| `__le__(self, other)` | `<=` |
| `__gt__(self, other)` | `>` |
| `__ge__(self, other)` | `>=` |

---

## ■ コンテナ（リストのように扱う）
| メソッド | 役割 |
|---------|------|
| `__len__(self)` | `len(obj)` |
| `__getitem__(self, key)` | `obj[key]` |
| `__setitem__(self, key, value)` | `obj[key] = value` |
| `__delitem__(self, key)` | `del obj[key]` |
| `__contains__(self, item)` | `item in obj` |

---

## ■ イテレータ関連
| メソッド | 役割 |
|---------|------|
| `__iter__(self)` | イテレータを返す |
| `__next__(self)` | 次の要素を返す（`for` 文で使用） |

---

# 3. 特殊メソッドを使うメリット
- クラスを Python の文法に自然に統合できる  
- `print(obj)` で見やすく表示できる  
- `obj1 + obj2` のような直感的な書き方が可能  
- `for x in obj:` のようにイテレーションできる  
- `len(obj)` や `obj[0]` のような操作を実装できる  

---

# 4. 例：`__str__(self)`
`__str__(self)` は、**オブジェクトを「人間が読みやすい文字列」に変換するための特別メソッド**です。

Python のクラスにこのメソッドを定義しておくと、  
`print(オブジェクト)` をしたときに、このメソッドの返り値が表示されます。

---

## ■ 役割  
- オブジェクトの内容をわかりやすく文字列として返す  
- `print()` や `str()` で呼び出される  
- デバッグやログ出力を見やすくするためによく使われる

---

## ■ 動作の仕組み  
例えば次のようなクラスがあるとします。

```python
class Sample:
    def __str__(self):
        return "これは Sample クラスの説明です"
```

このとき、

```python
obj = Sample()
print(obj)
```

とすると、  
`__str__()` が自動的に呼ばれて、次のように表示されます。

```
これは Sample クラスの説明です
```

---

## ■ まとめ  
- `__str__` は「オブジェクトの説明文」を返す特別メソッド  
- `print()` で自動的に呼ばれる  
- デバッグや表示をわかりやすくするために使う
