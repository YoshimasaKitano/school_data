# **多態性（polymorphism）** 


難しく感じるかもしれませんが実はシンプルで、「同じ操作を、違う型のオブジェクトに対して行える仕組み」のことです。
オブジェクト指向の中でも特に “Python らしさ” がよく出る概念です。  
---

##  Python における多態性とは？

**「同じメソッド名・同じ処理の書き方で、異なるクラスのオブジェクトを扱える」** という性質。

Python は “ダックタイピング” という考え方を採用しているので、  
「そのオブジェクトが何者か」よりも、**「そのオブジェクトが何ができるか」** を重視する。

---

#  ダックタイピングと多態性

Python の多態性はダックタイピングと相性が良い。

> 「アヒルのように歩き、アヒルのように鳴くなら、それはアヒルだ」

つまり、  
**同じメソッドを持っていれば、クラスが違っても同じように扱える**。

---

#  例：異なるクラスでも同じメソッド名を持てば多態性が成立

```python
class Dog:
    def speak(self):
        return "ワン！"

class Cat:
    def speak(self):
        return "ニャー！"

def animal_speak(animal):
    print(animal.speak())

dog = Dog()
cat = Cat()

animal_speak(dog)  # ワン！
animal_speak(cat)  # ニャー！
```

`Dog` と `Cat` は全く別のクラスだけど、  
**どちらも speak() を持っているので同じ関数で扱える**。  
これが多態性。

---

#  例：継承を使った多態性

```python
class Animal:
    def speak(self):
        raise NotImplementedError

class Dog(Animal):
    def speak(self):
        return "ワン！"

class Cat(Animal):
    def speak(self):
        return "ニャー！"
```

`Animal` を継承したクラスは、  
`speak()` をそれぞれの形で実装する。

これも多態性。

---

#  Python の多態性が便利な理由

- **コードの再利用性が高まる**
- **関数やメソッドが柔軟になる**
- **新しいクラスを追加しても既存コードを変えずに済む**
- **型に縛られない Python の強みを活かせる**

---

#  まとめ

- 多態性とは「同じ操作を異なるオブジェクトに対して行える仕組み」
- Python はダックタイピングにより、型よりも「できること」を重視
- 同じメソッド名を持つクラスなら、同じ関数で扱える
- 継承を使った多態性も一般的
- 柔軟で拡張しやすいコードが書ける
